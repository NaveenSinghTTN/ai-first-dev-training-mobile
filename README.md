# StreamList

A React Native OTT content discovery and watchlist app built as part of the AI-First Development Training Program.

Browse trending and top-rated movies, search for titles, view detailed content information, and manage a personal watchlist — all powered by the TMDB API.

## Project Specification

Full requirements, screen specifications, design system, API reference, and assessment rubric are documented in [project-spec.md](./project-spec.md).
