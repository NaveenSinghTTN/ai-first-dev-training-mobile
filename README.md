# AI-First Development Training Program

A two-phase training program for developers learning AI-first development with Cursor and React Native.

---

## Phase 1 — AI-First Development with Cursor

[phase-1/briefing.md](./phase-1/briefing.md)

Covers the mindset shift, Cursor skill checklist, the CDIR prompt framework, `.cursor/rules` exercise, and the Phase 1 deliverable (Prompt Strategy Document).

---

## Phase 2 — StreamList App

[phase-2/project-spec.md](./phase-2/project-spec.md)

Build a React Native OTT content discovery and watchlist app using the prescribed stack (TypeScript, React Navigation v6, Zustand, Axios, React Native CLI). Assessed on architecture, feature completeness, AI-first process, and judgment.
